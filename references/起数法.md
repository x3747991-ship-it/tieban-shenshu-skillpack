本文档是 `scripts/tieban.py` 的算法说明，用于核对、复现与二次开发。

## 一、条文库结构（data/tiaowen.json）

来源：`铁板神数条文.xls`（sheet = TBShSh）。

| 字段 | 键 | 含义 |

| 编号 | `n` | 条文号，1001–13000，共 12000 条 |

## 二、太玄配数（河洛理数）

天干、地支共用同一张配数表，口诀：

> 甲己子午九、乙庚丑未八、丙辛寅申七、丁壬卯酉六、戊癸辰戌五、巳亥四。

| 干支 | 太玄数 |
|---|---|
| 甲 / 己 / 子 / 午 | 9 |
| 乙 / 庚 / 丑 / 未 | 8 |
| 丙 / 辛 / 寅 / 申 | 7 |
| 丁 / 壬 / 卯 / 酉 | 6 |
| 戊 / 癸 / 辰 / 戌 | 5 |
| 巳 / 亥 | 4 |

八字 8 字（年干、年支、月干、月支、日干、日支、时干、时支）依序各配一数，得 `nums = [n0..n7]`。

---

## 三、天数与地数（河洛）

- **天数** = `nums` 中奇数之和
- **地数** = `nums` 中偶数之和

---

## 四、本命密钥

8 个太玄数依序连缀为 8 位整数：

```
key = n0n1n2n3n4n5n6n7   （字符串连缀再转 int）
```

该密钥为条文定位的唯一主键（同一个八字 → 同一份命书，完全确定）。

---

## 五、先天本命卦

1. **取九余**：`ju_yu(x) = (x - 1) % 9 + 1`，把正整数映射到 1–9。
2. 天数取九余 → 天数卦数；地数取九余 → 地数卦数。
3. **中宫寄卦**：余数为 5（中宫无卦）时，男寄艮（8）、女寄坤（2）。
4. **后天八卦数 → 卦名**：1 坎、2 坤、3 震、4 巽、6 乾、7 兑、8 艮、9 离（洛书数）。
5. **上下卦**：年干为阳干（甲丙戊庚壬）且男，或年干为阴干且女 → 「天数卦在上、地数卦在下」；否则上下对调。
6. 依 `(上卦, 下卦)` 查六十四卦名（见 `GUA64` 表）。

## 六、分类条文定位

八大分类（类别码 → 章节名 → 秘数偏移）：

| 类别码 | 章节 | 秘数偏移 |
|---|---|---|
| 5 | 一、性情禀赋 | 7 |
| 1 | 二、父母祖业 | 41 |
| 2 | 三、兄弟排行 | 27 |
| 3 | 四、婚姻夫妻 | 13 |
| 4 | 五、子女后嗣 | 59 |
| 6 | 六、事业功名 | 31 |
| 9 | 七、财帛家业 | 73 |
| 10 | 八、康宁寿元 | 97 |

> 秘数偏移为本技能包约定的确定性常量，可复现，可调整（调整即改变该分类命中条文，属参数化设计）。

**性别过滤**：男命取 `g ∈ {0,1}`，女命取 `g ∈ {0,2}`；若该类别在该性别下为空，则回退 `g = 0`。

**定位公式**：

```
pool     = 条文库中 c == 类别 且 g 通过性别过滤者（按编号升序）
index    = (key + 偏移) mod len(pool)
命中条文 = pool[index]
```

---

## 七、流年条文（类别 0）

1. 流年条文开头带「（岁数）」标记，可能是单岁「（47）」或双岁「（21、22）」。取数时解析括号内全部阿拉伯数字。
2. 给定年龄 `a` 时：候选 = 流年池中「括号内包含 a」的条文。
3. 命中 = `候选[(key + a × 31) mod len(候选)]`。
4. 未给年龄则跳过流年段。

---

## 八、确定性保证

同一输入（四柱 + 性别 + 年龄）必然得到同一输出；流程中不含随机、不含时间戳、不含外部状态。条文池按编号升序固定，取模索引唯一。

---

## 九、考刻校准（命例回填）

默认偏移是「约定常量」，命中条文具确定性但未必对应真人事实。**考刻**即以真实人生事实为锚，反推本盘正确刻度：

1. 在目标分类（性别过滤后、按编号升序的条文池）中，找到与事实最吻合的条文，记其索引 `idx`。
2. 反推本盘偏移：`off' = (idx − key) mod len(pool)`。
3. 其他分类同理；未给事实的分类保持默认偏移。
4. 本盘事实 + 各分类 `off'` 沉淀为命例卡，存 `data/cases/`（JSON），字段：`bazi / gender / key / ground_truth / calibrated / offsets / default_offsets`。

引擎复现：`tieban.py --case <命例卡路径>`（或 `--offsets '{"5":29,...}'`），`build_result(..., offsets=…)` 在定位时用 `offsets.get(cat, off)` 覆盖默认偏移。

硬锚点（可直接精确匹配）：父母生肖、兄弟排行、配偶生肖、子息数；软锚点（语义最近）：事业、性情、财运、健康。条文库为离散枚举，事实组合若库中无对应条文，应如实标注「无条」，不硬凑。

---

## 十、考刻可解性自检（单一交代数 δ 模型）

「能否由少数锚点唯一反推」取决于锚点是否**彼此相容**，而非数量。自检针对**单一交代数 δ** 模型（与逐维独立偏移相对）：

1. 每维锚点 = (类别, 目标条文号)，在性别过滤池中求目标索引 `idx`，得余数 `r = (idx − key) mod len(pool)`，约束为 `δ ≡ r (mod len)`。
2. 两维相容当且仅当 `(r_i − r_j) mod gcd(len_i, len_j) == 0`。
3. 全体锚点可被同一 δ 命中的充要条件是两两相容（广义中国剩余定理有解）。
4. **最大相容团**为能同时命中的最多锚点；团长 `lcm(len…)` ≥ 条文号上界 13000 时，交代数在该范围内唯一。

引擎入口：`tieban.py --selfcheck --anchors "类别:条文号,..."`，输出锚点明细 / 矛盾对 / 最大相容团 / 唯一性。函数为 `selfcheck(rows, key, gender, anchors)`。

**实测结论（本盘 99848558）**：8 个已考锚点两两矛盾 9 对，最大相容团仅 4 维（性情、父母、子女、事业），lcm = 15,101,298,876 ≫ 13000。即：相容时 2~3 锚点即唯一，不相容时超 4 个就无解。缺「师传秘数表」时，各维池长互异导致余数难两两相容，故当前引擎默认采用逐维独立偏移，各维各自命中事实条文。
