# 宫甲流度表（坤集 · 六亲网格）

本文档是铁板神数「坤集」六亲定位的核心映射，据张椿来《铁版神数》坤集（乾/坤/木/金四宫甲流度）与 12000 条条文库（`data/tiaowen.json`）逐行交叉验证而成。

**结论**：条文号一律以**条文库为准**（断语原文不得修改）；书上「宫甲流度表」给出了宫→六亲→条文号的映射规则，但个别密数存在刊误/OCR 错位，已在下表标注。

定位公式：

```
生肖式：  条文号 = 基础号 + 支步 × 地支序            （地支序：子0 … 亥11）
干支式：  条文号 = 基础号 + 支步 × 地支序 + 干步 × 干位
          干位：阳支(子寅辰午申戌)配阳干 甲丙戊庚壬 → 0..4
               阴支(丑卯巳未酉亥)配阴干 乙丁己辛癸 → 0..4
```

## 七、条文库干支标签转录偏差（已做标签纠错映射）

条文号分布是干净的等差网格（公式见上），但源库少数条目的**干支字被错写/误植**，导致正则按「妻命/夫命[干支]生」精确匹配时会错配或缺失。为此在 `scripts/tiaowen_grid.py` 中内置 `WIFE_GZ_LABEL_FIX` / `HUSBAND_GZ_LABEL_FIX` 两张**纠错映射**（正确干支键 → 正确条文号），共 11 键，使妻/夫网格达到 60/60 全覆盖。

| 宫 | 正确键 | 条文号 | 源库错写情况 |
|---|---|---|---|
| 妻 | 癸酉 | 10257 | 原文标「癸未」 |
| 妻 | 壬午 | 10107 | 原文标「庚午」 |
| 妻 | 乙酉 | 10217 | 原文标「己酉」 |
| 妻 | 己亥 | 10337 | 原文标「乙亥」 |
| 妻 | 己酉 | 10237 | 10217 误标「己酉」致 setdefault 取到 10217 |
| 妻 | 庚戌 | 10297 | 原文「庚**戊**生」（戌误作戊） |
| 夫 | 乙巳 | 10613 | 原文标「己巳」 |
| 夫 | 己巳 | 10633 | 原文「夫妻同己巳生」致正则漏配 |
| 夫 | 癸酉 | 10853 | 原文标「辛酉」 |
| 夫 | 乙亥 | 10913 | 原文标「癸亥」 |
| 夫 | 癸亥 | 10953 | 10913 误标「癸亥」致 setdefault 取到 10913 |

> **原则**：只订正「检索键」（定位到正确条文号），**不动 `tiaowen.json` 断语原文**（受「条文原文不得修改」约束）。故个别条文的字段内干支字仍保留源库原样（如 10217 输出「妻命**己**酉生」），此为可接受的显示偏差，不影响定位正确性。
